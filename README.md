## Fluxo de trabalho

A branch `main` é protegida. Todo código novo deve ser desenvolvido em uma branch própria
(ex: `feature/nova-rota`) e submetido via **Pull Request** para revisão antes do merge.

A revisão de Pull Requests dos colegas também conta como contribuição avaliada.
